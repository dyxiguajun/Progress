# Contributing

Open an issue with a small, redacted reproduction before a broad change. Keep source adapters separate from the core display model and preserve existing workspace compatibility. Run `pnpm test` and `pnpm build`; also run `pnpm extension:build` when changing the extension or its shared code. Describe actual checks and remaining limitations in the pull request. Never include real credentials, private endpoints, account screenshots or exported workspaces in issues or commits. See [repository contents](docs/REPOSITORY.md) for the public source boundary and publishing behavior. CI is not configured in this initial repository.
